# daita-economy

The DeSciX.net home page: a static site under `site/`.

`site/index.html`, `site/DeSciXAppSDK.js` and `site/images/` are build output of the EGPT-Evidence front-page generator (`scripts/build-frontpage.js daita-economy`, spec `site-src/frontpage/daita-economy.json` in DeSciX/EGPT). Edit the spec there and rebuild; do not hand-edit the output.
